# Iranized Scoreboard

The Iranized Scoreboard is a FiveM resource that provides a customizable and interactive scoreboard for FiveM servers. It displays player information such as ID, name, ping, health, and armor. The scoreboard can be toggled using a command or a key binding, making it easy for players to access and view the information they need.

## Install

1. Download the Iranized Scoreboard resource.
2. Extract the files into your FiveM server's `resources` directory.
3. Add the following line to your server configuration file (`server.cfg`):
   ```
   ensure IranizedScoreboard
   ```
4. Restart your FiveM server.

## Use

1. In-game, press the `F1` key to toggle the scoreboard.
2. The scoreboard will display a list of all active players along with their ID, name, ping, health, and armor.
3. Click the "Close" button to hide the scoreboard.
